# Gemini: локальное подключение

1. Открой https://aistudio.google.com/api-keys и создай Gemini API key в своём аккаунте Google.
2. Открой файл `/Users/tsukinoakari/.codex/.chatgpt-projects/g-p-6a4580c07dc881918a565e05e62ff07a/vlada-atlas/.env.local`. Пустой шаблон уже создан, если файла раньше не было. При необходимости скопируй `.env.example` в `.env.local`.
3. Найди переменную `GEMINI_API_KEY`.
4. Вставь свой ключ сразу после `=` в строке `GEMINI_API_KEY=` и сохрани файл. Ключ остаётся только на твоём компьютере; не отправляй его в чат.
5. Перезапусти сервер: останови текущий процесс через Ctrl+C, затем в папке проекта выполни `npm run dev` (Node.js 22 или новее). Порт в шаблоне — 3457.
6. Открой http://localhost:3457/#/profil → «Verbindung prüfen». «Gemini konfiguriert» означает, что сервер видит ключ. Для проверки действительного запроса открой математическое задание, заполни Lösungsweg и нажми «Rechenweg mit KI prüfen»: должен появиться разбор от Gemini по строкам и критериям. Если ключ неверный или исчерпана квота, сайт покажет конкретную причину; Musterlösung и Selbstkontrolle работают без KI.

## Как это устроено

Ключ читает только Node-сервер из environment или `.env.local` (резервно `.env`). Переменные окружения имеют приоритет. `.env*` и пользовательские данные исключены из Git; исключение — пустой `.env.example`. Закрытые файлы не выдаются через HTTP. Сервер передаёт ключ Google в заголовке, не в URL. Браузер отправляет задачу и решение своему серверу, без ключа. Проверка статуса возвращает только наличие конфигурации и название модели.

Модель по умолчанию — `gemini-3.6-flash`; её можно изменить через `GEMINI_MODEL`. Ответ KI — предложение оценки, не подтверждённая школьная отметка. Самооценка сохраняется отдельно. GitHub Pages обслуживает статические файлы и не запускает этот Node-сервер: для опубликованной версии понадобится серверное размещение и переменная окружения на нём.

Документация Google: https://ai.google.dev/gemini-api/docs/api-key
